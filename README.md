# 压缩式垃圾车 · 结构拆解图

一个自包含的交互式等距(isometric)手绘风格页面:拖动旋转垃圾车,开启透视模式查看内部压缩机构的工作过程。

直接用浏览器打开 `truck.html` 即可。

## 构建

`truck.html` 由 `core.js` 和 `src/*.js` 拼接生成:

```
python3 mk.py
```

## 涂装与垃圾桶

页面左上的「涂装」「垃圾桶」两个按钮（点开后选择，当前项高亮，按钮上的色点同步变化）。

- 涂装（`src/g_skin.js`）：经典绿（默认，与原外观逐色一致）、环卫橙、天空蓝、警示黄、雪白、深空灰、墨绿。
  只改箱体、驾驶室、上料机构和反光条的颜色；底盘、液压、桶和透视/选中的系统色不变。选择会记在浏览器里（无法存储时照常使用）。
- 无极调色板（同在「涂装」下拉里，预设下方的「自定义」）：箱体（含后门）、驾驶室、上料机构三个区域各选任意颜色，
  用「饱和度/明度」方块 + 色相条拖动（鼠标、触摸均可，实时重绘），也可输入 HEX（`#rgb` / `#rrggbb`，无效值不会生效）。
  亮、暗、中间三个色调由所选颜色自动算出，近白、近黑时会自动拉开层次；反光条固定为警示红。
  开始编辑即变为自定义涂装；之后再选预设，调色板回到该预设的颜色。自定义颜色同样记在浏览器里（松手/确认时写入，不是每次拖动）。
  逻辑在 `src/g_skin.js`，调色板界面在 `src/i_ui.js`，下拉里的「分组标题」和「面板」是 `core.js` 里 `buttons` 的通用能力（见 `mountFigure` 注释）。
- 垃圾桶（规格表 `src/e_bins.js`，几何 `src/e_lift.js` 的 `buildBin`）：三个维度可任意组合——
  **款式**（样子和结构都不同）、**容量**（每种款式有自己的几档）、**分类**（颜色和标识，所有款式都有）。

  | 款式（`binStyle`） | 容量（L） | 特点 |
  |---|---|---|
  | 两轮翻盖桶 `wheelie`（默认） | 120 / **240** / 360 | 常见的挂车塑料桶：锥形桶身、后铰链盖、两轮、推把（240 L 厨余与原来的绿桶逐点一致） |
  | 四轮大桶 `cart4` | **660** / 1100 | 四个轮子（后两个大轮、前两个万向轮带轮叉），平盖分成两瓣，两侧各一根推把；1100 L 主要是更深、更高，宽度不超过挂桶架 |
  | 圆形铁桶 `drum` | 100 / **200** | 16 棱柱铁桶，两道凸起的滚箍和顶沿，带旋钮的盖，没有轮子，直接立在地上，桶沿上焊着挂桶用的托架 |
  | 圆顶投放桶 `dome` | 120 / **240** | 圆角桶身，盖是一个分层的凸圆顶（可像盖一样向后掀开倒料），两侧各有带雨檐的投放口，两轮 |
  | 脚踏桶 `pedal` | 120 / **240** | 圆角桶身，桶背（远离车的一侧）有脚踏板和一根上到盖铰链的提杆，两轮 |

  分类 厨余垃圾（绿，默认）/ 其他垃圾（灰黑）/ 可回收物（蓝）/ 有害垃圾（红）。
  桶的尺寸、轮子、提手、盖铰链、倒料口位置都由规格表算出；倒料的垃圾从各款式真实的桶口落下。桶越大，每倒一桶装入车厢的量越多（240 L 为 20%，与容量成正比）。
  「垃圾桶」下拉按 款式 / 容量 / 分类 三组排列（当前项高亮）；容量一组只列出当前款式有的几档，换到没有当前容量的款式时自动取最接近的一档。
  只有桶没挂住、也没有在做动作时才能换桶，换后是满桶、盖关；换桶时旧桶滑向一侧、新桶从后面滑入（约 0.5 秒，只是画面上的位移，状态立即改变）。
  **桶也能调色**：「垃圾桶」下拉最下面的「颜色」组里，「跟随分类」（默认：桶身用分类的颜色）或「自定义」——
  与「涂装」里同一个无极调色板（饱和度/明度方块 + 色相条 + HEX，`src/i_ui.js` 的 `colorPicker`，涂装和垃圾桶共用）。
  自定义颜色只改桶身（亮、暗、中间色调由所选颜色按亮度自动算出，近白、近黑也有层次），分类的标识和标签照旧；换分类时保留自定义颜色，点「跟随分类」恢复分类色。
  调色只是外观，挂着桶或在工作时也能改（换款式、容量、分类仍然不行）；「垃圾桶」按钮上的色点就是桶的当前颜色。
  款式 / 容量 / 分类 / 颜色记在浏览器里（松手/确认时写入，不是每次拖动；无法存储或存了乱码时照常使用），刷新后还是这只桶；URL 参数优先。
  每个桶都满足挂桶架的限制（宽度不超过 24、立在地面、挂耳下沿正好落在梳齿上、前面避开压板和夹紧杆）；较矮的桶挂上时会被抬高一点，规格说明见 `src/e_bins.js` 文件头。
- URL 参数（非法值回退默认）：`?skin=classic|orange|sky|yellow|snow|graphite|forest`，
  `?body=RRGGBB&cab=RRGGBB&lift=RRGGBB`（箱体 / 驾驶室 / 上料机构，`#` 可省略，写成 `%23` 也行；写了任意一个有效值就是自定义涂装，
  没写的区域取 `?skin` 预设（默认经典绿）的颜色；无效值忽略；`?lift=` 后面是六位十六进制才算颜色，`?lift=1` 之类仍是上料机构的动作进度），
  `?binStyle=wheelie|cart4|drum|dome|pedal`，`?bin=<容量 L>`（取该款式有的容量，否则回到该款式的默认容量；
  没写 `binStyle` 的旧链接按容量推断款式，例如 `?bin=660` 就是四轮大桶 660 L，`?bin=120` 是两轮翻盖桶 120 L），`?binType=kitchen|other|recycle|hazard`，`?binColor=RRGGBB`（桶身自定义颜色，`#` 可省略，无效值忽略）。
  例如 `truck.html?skin=sky&binStyle=drum&bin=200&binType=recycle&binColor=e8348c`、`truck.html?bin=660&binType=recycle`、
  `truck.html?body=e8348c&cab=bfe3ff&lift=2b2f36`。

## 开发验证

- 普通回归测试：`node --test tests/regression.test.cjs`，使用 Node 内建测试模块。
- 浏览器回归测试：`python3 -m unittest discover -s tests -p 'test_browser.py'`。
  需要预先安装 Python Playwright 和本机 Chromium；测试不会自动安装或下载。
- 本地性能采样：`python3 benchmark.py --output shots/performance.json`，同样需要预先配置 Playwright。
  无头浏览器采样仅用于比较，不保证真实设备的 FPS。
- `shot.sh` / `pw.py` 是已有的截图辅助脚本。
