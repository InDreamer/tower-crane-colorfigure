# 塔式起重机 · 结构拆解图

一个自包含的交互式等距(isometric)手绘风格页面:拖动旋转塔式起重机,按系统拆开看结构(基础与塔身、回转与塔顶、起重臂、平衡臂、钢丝绳与吊钩、顶升与安全),
开启透视模式看驾驶室、卷筒、回转齿圈、油缸和泵站里面。包括:完整装配的三维模型(24 个零件,6 个系统)、拆解/合拢、点系统和点零件、透视、标签、涂装;
吊装工作流程(十步,吊钢筋捆在地面垫台和在建楼面之间来回)、顶升加节(五步,最多 6 节)、顺序提示、起重量曲线和力矩限制、钢丝绳 / 液压油流动、工作中亮起的标签和右上角读数。可替换的吊物(6 种款式 × 3 档尺寸 × 3 种吊索 × 任意颜色)和 6 套涂装预设。

直接用浏览器打开 `crane.html` 即可。

## 怎么玩

- 「拆解」：六个系统依次分开（先钢丝绳与吊钩，再起重臂、平衡臂、回转与塔顶、顶升套架，最后塔身），「合拢」按相反的顺序回位。分开后每个系统都有自己的空间，互不重叠。
- 点任一系统：只有它单独分离，系统名和它的零件标签亮出来；点系统名或空白处放回。分离后点它的零件：这个零件沿自己的方向被拉出（塔身节只拉出一节），再点收回。
- 「透视」：驾驶室、电控柜、起升机构护罩、回转机构护罩、泵站外壳、油缸缸筒变淡，露出操作台和座椅、绕了绳的卷筒、齿圈和小齿轮、活塞杆、泵与油箱；起重臂桁架淡一点，臂内的钢丝绳看得清。选中一个有外壳的零件时它的外壳也会淡出。
- 「工作」：自动连续做一次吊装,十步:回转到吊物上方、小车出去、落钩、挂钩、起升、回转回来、小车进来、放下、摘钩、收钩回位;每步 2.5–4 秒,步间停 0.8 秒。再按一次暂停;拆开状态下按会先合拢。下一次从楼面吊回垫台,两个方向轮流。
- 「顶升」：自动做一次加节,五步:平衡、顶升油缸伸出、引入标准节、拧螺栓、油缸收回;塔身加一节,最多 6 节(再按提示「已经最高了」)。吊着东西时不能顶升。
- 「分步」：下拉里每一步单独做一次;顶升加过节后可「恢复 4 节」(空闲时)。顺序不对时给中文提示,说明该先做哪一步。
- 工作时:钢丝绳里有流动的箭头(起升绳、变幅绳各自按方向),卷筒、吊钩滑轮、回转小齿轮按绳长转动,油只在顶升油缸伸缩时流动,正在动作的零件标签亮起;⑲ 力矩限制器超过 90% 额定吊重时变琥珀色,超载被拒绝时变红(吊物超过吊点的起重量:「太重了，起重机吊不动，换轻一点的」;只是小车开得太远:「太重了，小车往里开一点」)。右上角读数:吊重(t)、幅度(m)、高度(m)。
- 「吊物」：下拉里四组——款式(混凝土料斗、钢筋捆、工字钢梁、预制墙板、砖托盘、钢管束)、尺寸(这个款式自己的三档，重量写在后面)、吊索(两肢 / 四肢 / 吊带；这个款式用不了的灰着，点一下说明原因)、颜色(「跟随默认」，或下面的调色板拖成任意颜色，当前选项都有标记)。
  换款式时重量相近的尺寸会被选中。挂着吊物或正在动作时不能换款式、尺寸、吊索(提示「先摘钩，再换吊物」/「正在工作，等这一步做完」)，调色任何时候都行。换的时候旧吊物滑出垫台、新的滑进来，约 0.5 秒，只是画面；状态立即改变。右上角「吊物」一行写出当前选择，例如「钢筋捆 2.0t 四肢吊索」，吊重读数用所选重量。
  吊物重量：料斗 1.0/2.0/4.5 t，钢筋捆 1.2/2.0/2.7，工字钢梁 1.0/1.9/2.8，墙板 1.2/2.4/5.0，砖托盘 1.4/2.1/2.8，钢管束 1.1/1.9/2.8。垫台在 25.5 m 处，起重量 2.95 t，楼面在 21.8 m 处，3.5 t：4.5 t 的料斗和 5.0 t 的墙板超出曲线，起升会被拒绝(⑲ 变红，提示「太重了，起重机吊不动，换轻一点的」)，自动流程在这里停住，吊钩仍挂着吊物。
- 「涂装」：预设(经典黄、橙色、红白、绿色、蓝白、粉色)，下面「自定义」是三个区域的调色板。
- 场景:地面垫台上的吊物(默认钢筋捆 2.0 t)、在建楼(楼面高 24)、四根吊索(属于 ⑨);场景不带编号,拆开时淡出。
- 「标签」：零件编号与名称（编号 ①–㉔ 同参考图），按系统分色，分左右两列，引线不交叉，不压在起重机上。手机宽度（≤560px）下标签变成编号徽章，名称列在图下面。

## 构建

`crane.html` 由 `core.js` 和 `src/*.js`(按文件名排序)拼接生成:

```
python3 mk.py
```

| 文件 | 内容 |
|---|---|
| `src/a_base.js` | 调色板、系统与零件表(文件头是规格)、坐标系 `makeFrames`、`solid/gB/gPr/gR/gCyl/gHose` 等几何助手 |
| `src/b_tower.js` | 基础(十字梁 + 4 块配重混凝土)、基础节、标准节(`nsec` 4..6)、爬梯与休息平台 |
| `src/c_slew.js` | 回转支承与回转机构、驾驶室、塔顶、力矩限制器 / 风速仪 / 障碍灯 |
| `src/d_jib.js` | 起重臂(三角形桁架)、小车与变幅机构、起重臂拉杆 |
| `src/e_counter.js` | 平衡臂、平衡重、起升机构、电控柜、平衡臂拉杆 |
| `src/f_loads.js` | 吊物:6 款式 × 3 尺寸 × 3 吊索 × 颜色，规格表和吊挂约束写在文件头 |
| `src/f_site.js` | 场景:垫台、在建楼、吊索(钢丝绳带套环 / 吊带)、换吊物的滑入滑出 |
| `src/g_work.js` | 工作状态、起重量曲线、步骤表、提示 `whyNot`、`scrub` |
| `src/f_rope.js` | 吊钩组、导向滑轮、起升钢丝绳与变幅钢丝绳(按切线算路径,每个端点都落在卷筒 / 滑轮 / 锚点上) |
| `src/f_climb.js` | 顶升套架、顶升油缸、液压泵站 |
| `src/g_skin.js` | 涂装 |
| `src/h_scene.js` | 零件排序(画家算法)、标签、`scene()` |
| `src/i_ui.js` | 拆解 / 合拢 / 选择、工作步骤、调色板界面、`mountFigure` |

## 涂装

页面左上的「涂装」按钮：六个预设「经典黄」(默认，参考图的颜色)、橙色、红白、绿色、蓝白、粉色，和下面「自定义」里的调色板——塔身与臂架（所有黄色桁架）、驾驶室、机构电机（蓝色）三个区域各选任意颜色，
用「饱和度/明度」方块 + 色相条拖动（鼠标、触摸均可，实时重绘），也可输入 HEX（`#rgb` / `#rrggbb`，无效值不会生效）。
平衡重、钢丝绳、吊钩的黄黑条纹、液压件、混凝土块不随涂装变化。选择记在浏览器里（`tower-crane.paint`；无法存储时照常使用）。

## URL 参数（非法值回退默认）

- 视角与显示：`yaw` `pitch`(度)、`xr=0..1`(透视)、`ex=123456`(拆开哪些系统，只认数字 1..6)、`sel=<系统 1..6>` `sub=<零件 1..24>`(零件必须属于被选的系统，否则只选系统；只给 `sub` 就选它所在的系统)。
- 工作状态：`slew=<度>`(回转)、`trolley=<x>`(小车位置，32..90)、`hookZ=<z>`(吊钩高度，20..76，默认 62，每多一节下限降 16)、`nsec=4..6`(标准节数)、`climb=0..1`(顶升进度)、`at=pad|roof`(吊物在哪)、`hooked=0|1`(吊物挂在钩上)、`loadT=0.2..8`(吊物重量，演示超载)、`step=<步骤>&t=0..1`(直接打开某一步的中途,前面的步骤算作已做完)。
- 吊物：`loadStyle=hopper|rebar|beam|panel|pallet|pipes`、`loadSize=s|m|l`、`rig=two|four|belt`(这个款式用不了的吊索回到它自己的默认)、`loadColor=RRGGBB`；非法值回退默认；网址优先于浏览器里记住的选择(`tower-crane.load`，只在点选或松手时写入，无法存储时照常使用)。`loadT` 仍可单独指定重量(测试用)。
- 涂装：`skin=classic|orange|redwhite|green|bluewhite|pink`，`tower=RRGGBB&cab=RRGGBB&motor=RRGGBB`（`#` 可省略，写成 `%23` 也行；写了任意一个有效值就是自定义涂装，没写的区域取预设的颜色）。

例如 `crane.html?yaw=110&pitch=28&slew=60&trolley=70&hookZ=30`、`crane.html?ex=123456`、`crane.html?tower=e8348c&cab=bfe3ff&motor=2b2f36`。

## 开发验证

- 普通回归测试：`node --test tests/regression.test.cjs`，使用 Node 内建测试模块。
  包含几何检查（每个零件是凸体、绳端接触卷筒 / 滑轮 / 锚点、小车轮子压在下弦上、吊钩垂直挂在小车下、整机没有零件互相穿插）和
  用射线投射做的画家算法检查（`ORDER_REPORT=1` 打印每个视角错序对数）。
- 浏览器回归测试：`python3 -m unittest discover -s tests -p 'test_browser.py'`（约 9 分钟，工作中标签引线在 12 个方位 × 15 步上逐一测量）。
  需要预先安装 Python Playwright 和本机 Chromium；测试不会自动安装或下载。
- 本地性能采样：`python3 benchmark.py --output shots/performance.json`，同样需要预先配置 Playwright。
  无头浏览器采样仅用于比较，不保证真实设备的 FPS。
- `pw.py` 是截图辅助脚本：`OUT=crane.html python3 pw.py "yaw=110&pitch=28" '[["wait",900],["shot","name"]]' 1400 1000` → `shots/name.png`。
